# CS 405: Secure Coding

Joshua Kelly — Southern New Hampshire University

This repository contains my portfolio work for CS 405. Throughout the course, I worked with C++ security issues, tested code, and developed a security policy for Green Pace. One of the main things I took from this course is that security needs to be part of development from the beginning.

## Repository contents

- **Project-One/** — My completed Green Pace security policy, covering secure coding standards, risk assessment, encryption, and authentication, authorization, and accounting.
- **Project-Two/** — My presentation reviewing the policy and the results of the unit tests.
- **Coding-Assignments/** — My course submission ZIPs for numeric overflow, buffer overflow, SQL injection, exceptions, unit testing, encryption, and static code analysis.
- **Portfolio-Reflection/** — My Module Eight journal reflecting on secure coding standards, risk and mitigation, zero trust, and security policies.

The documents, presentation, and ZIP files are copies of my saved course artifacts, preserved without changes. Some ZIPs include supporting files or libraries used in the assignments.
